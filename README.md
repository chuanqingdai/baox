# 保罗万相独立站

从 KnowLens 主站的 `/baox-new` 页面组迁移出来的独立网站。

## 页面路由

- `/` 首页
- `/masterclass` AI保险大师课
- `/poster` 保险海报
- `/tool` 工具包
- `/lab` 学员作品集
- `/about` 关于我们

## 本地运行

```bash
npm install
npm run dev -- -p 3001
```

当前工作台按钮指向线上地址：

```text
https://baox.ai/index.html
```

## 构建

```bash
npm run build
```
