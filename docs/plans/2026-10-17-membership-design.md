# BAOX.AI 会员系统

## 范围
- 账号与密码注册，头像、昵称；登录弹窗、个人中心、后台。
- 普通会员 / AI大师天使群 / 团队内部成员，分别为星芒 / 翼环 / 盾冠徽章。
- 会员级别与管理员权限分离。只能由管理员修改级别、标签、状态、页面规则。
- 账号 jaydenkong、昵称公子，通过本地环境中的密码散列初始化。任何密码不进入仓库。

## 设计
保留现有页面，页眉右侧注入登录或个人中心入口。黑金配色，细描边、宋体标题、克制留白。
个人中心显示会员卡、资料、已开放页面、密码设置。后台提供用户搜索、分级筛选、标签及状态编辑、会员页面权限矩阵。

## 后端
Vercel Node Functions + PostgreSQL（兼容 Supabase 连接池）。服务端 scrypt 密码散列、随机会话，数据库只存会话摘要。HttpOnly / Secure / SameSite=Lax Cookie；修改操作校验同源。数据库持久化限流，后台操作审计。
角色权限读取数据库，普通会员不可升级自己。团队成员可看全部前台页面，后台仅管理员可看。保藏不允许游客访问。其余页面默认保持公开，可在后台收紧权限；首页始终公开。
所有受控 HTML 不进入静态 dist，通过后端鉴权后返回。无数据库时仅公开页面允许访问，保藏和后台拒绝访问。静态资源允许缓存，用户与权限响应禁止缓存。

3. 真实 PostgreSQL 引擎测试注册、会话、密码、权限、禁用、越权、限流、静态绕过与路由。
4. 本地桌面与手机预览，构建及部署包检查。

## 数据与部署
生产数据独立于代码部署，不能放在 Vercel 临时文件系统。需要数据库连接及 Vercel 项目配置权限。未接入生产数据服务前不替换正在运行的网站。
