# 保藏 · 应用封面标准

这是公子于2026-10-17指定的后续新增应用默认规范。

## 视觉与输出

参考 `collection/assets/reimbursement-vox.webp` 和用户上传的 MG-VOXSTAGE 风格标准图。米色旧纸、黑白摄影网点、撕纸边缘、朱红箭头或符号、少量赭金强调；避免过量装饰，缩小为卡片后仍可看清用途。封面无标题、口号、品牌、水印及说明文字，不用产品截图。

源画幅16:9，交付960×540 WebP，每张小于100000 bytes。以 cwebp 质量80、method6为起点，必要时设定94000 bytes目标。主视觉留出安全边距，适配当前2:1卡片容器的轻微上下裁切。沿用懒加载和异步解码。

## 已定构图及生成提示方向

均使用内置 image_gen；附已有报销封面作为风格参考，禁止复用其医疗内容。

- 活动量跟踪仪：无数字日历格、红色勾选、手持打卡印章、递增的赭金柱形图、红色向上箭头与成就徽章，体现每日任务、打卡和积累成长。
- 直播神器：黑白摄影质感的麦克风、摄像机、提词器玻璃与仅有抽象横线的文稿，红色广播信号、对话气泡与小型合规盾牌，体现直播提词、控场互动与内容合规。
- 报销测试仪：医院、医疗票据、计算器，红色箭头指向手掌中的金币，并以淡化的区域地图表达覆盖范围。

新增应用先提炼其主要操作与收益，再选择2–4个直观对象组织成一幅画面，保持统一材质和色彩，不照搬已有应用的主体。
